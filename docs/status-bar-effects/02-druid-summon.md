# 장면 2 — 드루이드 소환술: 정령 동물이 튀어나간다

> **한 줄 컨셉**: 가부좌를 틀고 앉은 드루이드가 손으로 인을 맺고 주문을 외우면, 바닥 마법진에서 빛으로 된 정령 동물들이 쏟아져 나와 스트립 끝까지 내달린다.

| 항목 | 값 |
| --- | --- |
| 장면 ID | `druid` |
| 우선순위 | 3순위 (스프라이트가 가장 많음) |
| 핵심 부품 | 파티클(5.1), 잔상(5.3), 시차 스크롤러·바람(5.7), 다수 개체 관리 |
| 예상 스프라이트 | 드루이드 1명(약 16프레임), 정령 동물 5종 × 4~6프레임, 마법진 4프레임, 덩굴·꽃 타일 |
| 영감 | 소환술 연출 장르 일반. 특정 작품의 식신·인(印) 모양은 쓰지 않는다 |

## 1. 무대 구성

```
 x: 0   10                                                                      W
    ┌─────────────────────────────────────────────────────────────────────────────┐
 0  │      ᐟ ᐟ 룬 문자가 위로 떠오름                     ⌒v⌒ (새 떼 레인)            │
 4  │                                                                             │
    │   ◯   ← 머리 위 빛 고리                                                       │
11  │  (▓▓)  ══ 뒤 레인(작고 어둡게) ══════════════════════════════▶               │
    │  /██\  ══ 앞 레인(크고 밝게)   ════════════════════════════════▶             │
16  │ ⊂════⊃ ← 납작한 타원 마법진 (지면에 2~3px 높이로)                              │
    │ ,,,,,,,,,,,,,,,,,,,, 풀 (동물이 지나가면 물결처럼 눕는다) ,,,,,,,,,,,,,,,,,,,,,,, │
22  └─────────────────────────────────────────────────────────────────────────────┘
```

**깊이감 만들기**: 세로가 짧으니 "레인" 2~3줄로 원근을 흉내 낸다.

| 레인 | y 기준선 | 크기 배율 | 밝기 | 속도 배율 |
| --- | --- | --- | --- | --- |
| 하늘 | 3 | 0.6 | 70% | 1.2 |
| 뒤 | 13 | 0.75 | 60% | 0.85 |
| 앞 | 18 | 1.0 | 100% | 1.0 |

### 대기(IDLE) 중 살아 있는 요소
- 드루이드 호흡(어깨 1px 오르내림, 4초 주기).
- 머리 위에 작은 나뭇잎 1~2장이 빙글빙글 떠다님.
- 풀이 바람에 천천히 물결침(시차 스크롤러 + 사인파 기울기).
- 가끔(15%) 작은 다람쥐/새 한 마리가 배경을 지나감. **진짜 동물**(정령 아님, 색 있음) → 소환된 정령과 대비가 된다.
- 반딧불 3~5개.

## 2. 캐릭터 스프라이트 (드루이드)

| 동작 | 프레임 | fps | 설명 |
| --- | --- | --- | --- |
| `meditate` | 4 | 4 | 가부좌, 눈 감고 호흡 |
| `seal` | 3 | 8 | 손을 가슴 앞으로 모아 인을 맺음 (오리지널: 두 손바닥을 맞대고 손가락을 깍지 낀 모양) |
| `chant` | 2 (루프) | 8 | 입 1px 움직임 + 몸 주변 오라 |
| `release` | 3 | 12 | 두 팔을 앞으로 활짝 펼침, 망토 뒤로 휘날림 |
| `exhale` | 2 | 4 | 숨 내쉬며 원래 자세로 |

크기: **14 × 14** (앉아 있어서 작다), 기준점: 엉덩이 가운데. 머리 장식(사슴뿔 모양 나뭇가지 관) 끝이 y = 4까지 올라온다 → 앉아 있어도 실루엣이 뚜렷하다.

## 3. 시퀀스

| # | 상태 | 길이 | 화면에서 일어나는 일 |
| --- | --- | --- | --- |
| S1 | CHARGE ① 인 맺기 | 0.4초 | `seal`. 바람이 멈춤(풀 물결 속도 → 0). 반딧불들이 드루이드 쪽으로 천천히 모임 |
| S2 | CHARGE ② 주문 | 0.8~1.4초 | `chant`. 바닥에 **마법진이 왼쪽에서 오른쪽으로 그려짐**(타원 둘레를 따라 1px 빛 점이 달림, 4프레임 문양 회전). 몸 주변에서 룬 문자 3~5개가 떠올라 위로 사라짐. 마법진 위로 빛 기둥이 1px씩 자람 |
| S3 | CAST | 0.12초 | `release`. 마법진에서 **세로 빛 기둥 폭발** + 나뭇잎 버스트 12개 사방으로. 히트스톱 0.08초 |
| S4 | TRAVEL | 1.2~2.5초 | 변형에 맞는 정령 동물들이 시간차로 튀어나와 오른쪽으로 질주 (아래 표). 지나가는 곳마다 풀이 눕고, 발자국 자리에 꽃이 피었다 진다 |
| S5 | IMPACT | 0.4초 | 동물들이 오른쪽 끝에 닿으면 **빛 입자 + 나뭇잎으로 흩어짐**. 마지막 개체가 닿을 때 작은 흔들림 |
| S6 | AFTERMATH | 2~3초 | 흩어진 빛 입자 일부가 **천천히 왼쪽으로 되돌아와** 드루이드 머리 위 고리에 흡수됨 (순환의 마무리). 꽃이 시들며 풀로 돌아감. 마법진 페이드아웃. `exhale` → `meditate` |

## 4. 정령 동물 (변형)

정령 동물은 **단색 실루엣 + 1px 밝은 외곽 + 잔상 3개 + 꼬리 파티클**로 그린다. 저해상도에서 디테일 대신 *움직임의 리듬*으로 어떤 동물인지 알아보게 하는 게 핵심이다.

| ID | 가중치 | 동물 / 크기 | 동작 패턴 | 개수 | 색 |
| --- | --- | --- | --- | --- | --- |
| `wolf_pack` | 30 | 늑대 12×7 | 6프레임 질주(갤럽), 몸이 위아래 1px 출렁. 선두가 중간에 한 번 고개 들어 하울링(0.3초 정지) | 3~5마리, 앞·뒤 레인에 섞어서 0.15~0.3초 간격 | `#9FE8FF` 청백 |
| `stag_leap` | 20 | 사슴 12×12 | 큰 포물선 점프 3~4회로 건너감. 착지할 때마다 꽃 고리가 퍼짐 | 1~2마리 | `#C8FFB0` 연녹 |
| `hawk_flock` | 20 | 매 6×4 | 하늘 레인에서 사인파 비행(진폭 2, 주기 0.6초). 날갯짓 4프레임. 대열이 V자 → 일자로 바뀜 | 5~9마리 | `#FFE79A` 금빛 |
| `vine_rush` | 15 | 동물 대신 **덩굴** | 지면을 따라 덩굴이 왼쪽 → 오른쪽으로 빠르게 자람(머리 끝이 꿈틀). 줄기에서 잎과 꽃이 순서대로 터짐. 끝나면 오른쪽부터 시들어 흙으로 | 덩굴 1~2줄 | `#7BE38A`, 꽃 `#FF9FCB` |
| `boar_charge` | 10 | 멧돼지 14×9 | 짧은 다리로 다다다 돌진(4프레임 빠르게). 지나가며 흙먼지 파티클. 끝에서 바위를 들이받는 듯 큰 충격 | 1마리 + 새끼 2마리가 뒤에서 졸졸 | `#FFC28A` 호박 |
| `great_spirit` ★레어 | 5 | **거대 정령 사슴** 32×20 (세로를 거의 다 씀) | 천천히 걸어서(3초) 건너감. 발걸음마다 지면 전체가 0.5초 동안 꽃밭이 됨. 뿔에서 빛 입자가 계속 떨어짐. 하늘엔 반딧불 30개 | 1마리 | `#FFFFFF` + 무지개빛 외곽 순환 |

### 정령 렌더링 규칙
- 몸체 alpha 0.85, add 혼합 글로우 1px.
- 잔상 3개(간격 2프레임, alpha 0.4/0.25/0.1).
- 꼬리 파티클: `rate 20, life [0.3, 0.6], size 1, colors [동물색, 흰색], blend add`.
- 레인 간 겹침: 뒤 레인을 먼저 그리고 앞 레인을 나중에. 겹치는 부분은 앞 레인 개체가 덮는다.

### 군집 개체 생성 규칙

```ts
spawnPack(variant) {
  const n = randInt(variant.count[0], variant.count[1]);
  for (let i = 0; i < n; i++) {
    schedule(i * rand(0.15, 0.3), () => spawn({
      kind: variant.animal,
      lane: weightedPick({ front: 0.6, back: 0.4 }),
      speed: variant.speed * rand(0.9, 1.15),  // 기본 W / 1.6초
      phase: rand(0, 1),                       // 애니메이션 시작 프레임 다르게
    }));
  }
}
```

- 선두가 오른쪽 끝에 닿기 전에 마지막 개체가 출발해야 한다 → "줄지어 달리는" 그림이 나온다.
- 앞 개체를 따라잡으면 살짝 레인을 바꾸거나 속도를 맞춘다 (겹쳐서 한 덩어리로 보이지 않게).

## 5. 환경 반응 (가로 공간을 "살아 있게" 만드는 부분)

| 반응 | 트리거 | 내용 |
| --- | --- | --- |
| 풀 눕기 | 동물이 x를 지날 때 | 해당 x ±4 범위 풀이 진행 방향으로 기울었다가 0.5초 동안 탄성 복귀 |
| 발자국 꽃 | 앞 레인 동물의 발 프레임 | 30% 확률로 1~2px 꽃이 피고 1.5초 후 짐 |
| 진짜 동물 도망 | IDLE 때 지나가던 다람쥐/새가 있으면 | 소환 순간 깜짝 놀라 위로 튀어 도망감 |
| 바람 | CAST 직후 | 시차 스크롤 속도를 0.5초간 3배 → 나뭇잎 파티클이 오른쪽으로 쓸려감 |

## 8. 완료 기준 체크리스트

- [ ] 드루이드가 앉은 상태로도 실루엣(나뭇가지 관)이 알아보인다
- [ ] 마법진이 왼쪽에서 오른쪽으로 "그려지는" 과정이 보인다
- [ ] 동물 변형 6종이 가중치대로 나오고 연속 중복이 없다
- [ ] 정령 동물이 정지 화면 한 장만 보고도 종류 구분이 된다 (실루엣 테스트)
- [ ] 앞·뒤 레인의 크기와 밝기 차이로 원근감이 느껴진다
- [ ] 동물이 지나간 자리에 풀/꽃 반응이 남는다
- [ ] AFTERMATH에서 빛이 드루이드에게 돌아와 순환이 닫힌다
- [ ] 동시 개체 상한(동물 10, 파티클 120)을 넘지 않는다
- [ ] IDLE 15fps 이하, 이펙트 구간 30fps 유지

## 9. 미정 / 로컬에서 결정할 것

- [ ] 정령 동물 종류를 사용자가 "도감"처럼 모으는 기능 (처음 본 동물 기록, 레어 발견 알림)
- [ ] 계절에 따라 꽃 색·풀 색을 바꿀지
- [ ] 드루이드 성별·외형을 고를 수 있게 할지 (팔레트 스왑 2~3종)
