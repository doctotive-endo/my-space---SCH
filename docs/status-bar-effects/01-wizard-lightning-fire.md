# 장면 1 — 마법사: 번개 마법 → 화염 마법

> **한 줄 컨셉**: 왼쪽 끝의 작은 마법사가 지팡이를 들면, 스트립 끝까지 번개가 쫙 뻗고, 이어서 화염이 바닥을 타고 휩쓸고 지나간다.

| 항목 | 값 |
| --- | --- |
| 장면 ID | `wizard` |
| 우선순위 | 2순위 (공통 엔진 → 장면 3 다음) |
| 핵심 부품 | 절차적 번개(5.2), 파티클(5.1), 화면 플래시(5.5), 흔들림(5.6) |
| 예상 스프라이트 | 마법사 1명(약 20프레임), 화염구 4프레임, 폭발 6프레임, 구름 타일 1장 |

---

## 1. 무대 구성

```
 x: 0    12                                                                     W
    ┌─────────────────────────────────────────────────────────────────────────────┐
 0  │            ░░░ 구름(번개 때만 오른쪽에서 밀려 들어옴) ░░░                     │
 4  │   ▲                                                                         │
    │  /●\  ← 지팡이 끝 오브(발사점, x≈14, y≈8)                                    │
11  │  |█|  ═══════════════  메인 이펙트 레인  ═══════════════════════▶            │
16  │  / \                                                                        │
    │ ,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,, 풀 / 돌길 ,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,, │
22  └─────────────────────────────────────────────────────────────────────────────┘
```

| 레이어 | 내용 |
| --- | --- |
| L1 원경 | 먼 산 실루엣(아주 어둡게), 번개 때만 비치는 구름 |
| L2 지면 | 풀 + 군데군데 돌. 화염 뒤에는 그을음 타일로 교체됐다가 3초 동안 서서히 원래대로 |
| L3 캐릭터 | 마법사 (기본 위치 x = 12, 데드 존이면 오른쪽으로 옮김) |
| L4 이펙트 | 번개 본줄기·가지, 화염구, 화염파 |
| L5 근경 | 스파크, 불씨, 연기 |
| L6 오버레이 | 번개 플래시(흰-하늘), 화염 때 주황 색조 |

### 대기(IDLE) 중 살아 있는 요소
- 망토 끝 2프레임 펄럭임, 지팡이 오브가 2초 주기로 은은하게 깜빡임.
- 반딧불 같은 마나 입자 2~4개가 캐릭터 주변을 천천히 떠다님.
- 가끔(20%) 마법사가 하품하거나, 지팡이로 바닥을 톡 두드려 작은 빛 링을 만든다 (미니 변형).

## 2. 캐릭터 스프라이트

| 동작 | 프레임 | fps | 설명 |
| --- | --- | --- | --- |
| `idle` | 4 | 6 | 숨쉬기, 망토 펄럭 |
| `charge` | 2 (루프) | 10 | 지팡이를 앞으로 겨눔, 몸 살짝 뒤로 젖힘 |
| `cast_bolt` | 3 | 12 | 지팡이를 앞으로 찌르듯 뻗음 |
| `cast_fire` | 3 | 12 | 지팡이를 아래에서 위로 휘둘러 올림 |
| `recoil` | 2 | 10 | 반동으로 반 발짝 뒤로 |
| `pose` | 2 | 4 | 의기양양 (모자 고쳐 쓰기) |

크기: **16 × 18**, 기준점: 발 가운데. 모자 끝은 y = 2까지 올라와도 된다.

## 3. 시퀀스 A — 번개 마법

| # | 상태 | 길이 | 화면에서 일어나는 일 |
| --- | --- | --- | --- |
| A1 | CHARGE | 0.6~0.9초 | 구름 타일이 오른쪽에서 상단 존(y 0~4)으로 밀려 들어옴. 오브 주변에 작은 스파크 3~6개가 **안쪽으로 빨려 들어감**. 짧은 미니 번개(길이 4~8)가 오브 주변에서 지직. 풀이 정전기로 살짝 곤두섬(풀 타일 1프레임 교체) |
| A2 | CAST | 0.08초 | 오브 → 오른쪽 끝(x = W−2)까지 **본줄기 번개 생성**. L6 플래시 alpha 0.6. 히트스톱 0.06초 |
| A3 | TRAVEL(유지) | 0.4~0.8초 | 번개가 2~3프레임마다 모양 재생성. 가지 2~4개가 아래로 꺾여 **지면에 닿는 곳마다 스파크 버스트**(6~10개). 위쪽 가지는 구름으로 이어짐 |
| A4 | 재타격 | 0~2회 | 50% 확률로 0.15초 뒤 한 번 더 (두께 1단계 줄임). 플래시는 1초 3회 이내 규칙 |
| A5 | IMPACT | 0.3초 | 오른쪽 끝에서 원형 스파크 폭발 + 흔들림 x ±1. 맞은 자리 지면에 검게 탄 자국 |
| A6 | AFTERMATH | 1.0~1.5초 | 번개가 있던 자리에 **잔광 점선**(1px, 하늘색, alpha 0.4 → 0)이 남았다가 사라짐. 공기 중 이온 입자가 위로 떠오름. 구름이 왼쪽으로 빠져나감 |

### 번개 파라미터

| 파라미터 | 기본값 | 범위 |
| --- | --- | --- |
| `depth` | 7 | 6~8 |
| `roughness` | 5 | 3~7 |
| 본줄기 두께 | 코어 1px + 글로우 1px | 강한 변형은 코어 2px |
| 가지 수 | 3 | 1~5 |
| 재생성 간격 | 2프레임 | 1~3 |
| 색 | 코어 `#FFFFFF`, 글로우 `#8FD3FF`, 잔광 `#4A7BFF` | |

### 번개 변형 (가중치)

| ID | 가중치 | 내용 |
| --- | --- | --- |
| `bolt_straight` | 40 | 기본: 오브에서 오른쪽 끝까지 한 줄기 |
| `bolt_chain` | 25 | **연쇄 번개**: 레인 위에 놓인 3~5개 표식(돌, 허수아비)을 차례로 튀며 건너감. 각 표식에서 0.05초 정지 |
| `bolt_sky` | 20 | **낙뢰**: 구름에서 지면으로 세로 번개 4~6발이 왼쪽 → 오른쪽 순서로 0.1초 간격 투하. 가로 공간을 "순차적으로" 채움 |
| `bolt_ball` | 10 | **구전(球電)**: 지지직거리는 빛 공이 천천히(2초) 오른쪽으로 굴러가며 주변에 작은 아크를 튀김 |
| `bolt_storm` ★레어 | 5 | 구름이 스트립 전체를 덮고 본줄기 3개가 동시에 위·가운데·아래로 뻗음. 끝나고 비 파티클 3초 |

## 4. 시퀀스 B — 화염 마법

번개 직후 **콤보 확률 45%**로 IDLE 없이 바로 이어진다. 아니면 다음 사이클에 따로 나온다.

| # | 상태 | 길이 | 화면에서 일어나는 일 |
| --- | --- | --- | --- |
| B1 | CHARGE | 0.6~0.8초 | 오브 색이 파랑 → 주황으로 바뀜. 오브 위쪽에 **열 아지랑이**(픽셀 몇 개가 위아래 1px씩 흔들림). 불씨가 위로 피어오름. L6 색조를 아주 약한 주황으로 |
| B2 | CAST | 0.1초 | `cast_fire` 자세. 오브에서 작은 폭발 링. 히트스톱 0.04초 |
| B3 | TRAVEL | 0.8~1.2초 | 변형에 따라 화염이 왼쪽 → 오른쪽으로 진행 (아래 표). 지나간 자리 풀은 그을음 타일로 교체 |
| B4 | IMPACT | 0.4초 | 오른쪽 끝에서 폭발: 6프레임 폭발 스프라이트 + 바깥으로 퍼지는 링 + 흔들림 |
| B5 | AFTERMATH | 2~3초 | 연기가 위로 오르며 **왼쪽으로 흘러감**(바람). 불씨 파티클이 천천히 떨어짐. 그을음이 오른쪽부터 서서히 풀로 돌아옴. 마법사 `pose` |

### 화염 변형 (가중치)

| ID | 가중치 | 내용 | 가로 공간 활용 |
| --- | --- | --- | --- |
| `fire_wave` | 40 | **화염 파도**: 높이 6~10의 불기둥 벽이 지면을 타고 오른쪽으로 번져 나감. 앞쪽 가장자리는 높고 밝고, 지나간 뒤쪽은 낮아지며 꺼짐 | 스트립 전체를 시간차로 훑음 |
| `fire_ball` | 30 | **화염구**: 4프레임 회전 화염구가 날아감. 꼬리에 불씨 트레일(rate 60/s). 비행 중 위아래로 ±1 출렁 | 꼬리가 길게 남아 선처럼 보임 |
| `fire_stream` | 20 | **화염 방사**: 오브에서 오른쪽 끝까지 계속 뿜어지는 불줄기 1.2초. 파티클 기반(콘 각도 ±6°) | 가로 전체가 동시에 불바다 |
| `fire_phoenix` ★레어 | 5 | 화염이 **새 모양 실루엣**(12×8, 날개짓 4프레임)이 되어 날아감. 지나간 자리에 깃털 모양 불꽃이 떨어짐 | |
| `fire_meteor` ★레어 | 5 | 오른쪽 위 하늘에서 운석이 비스듬히 떨어져 오른쪽 1/3 지점에 착탄. 큰 흔들림 | |

### 화염 파티클 (fire_wave 기준)

```json
{
  "rate": 90, "life": [0.3, 0.7], "speed": [4, 10], "angle": [-100, -80],
  "gravity": -12, "drag": 0.92, "size": [1, 2],
  "colors": ["#FFF6C2", "#FFC94A", "#FF7A1A", "#C2311A", "#3A2A2A"],
  "blend": "add", "maxAlive": 70
}
```

- 색 순서: 흰노랑 → 노랑 → 주황 → 빨강 → (마지막은 normal 혼합의 연기 회색).
- 불길 실루엣은 파티클만으로 만들지 말고, **3프레임 불꽃 타일**(8×10)을 깔고 그 위에 파티클을 얹으면 저해상도에서도 형태가 산다.

## 6. 사이클 예시 (실제로 보이는 흐름)

```
0s     IDLE (7.2초) ─ 마나 입자 둥둥, 망토 펄럭
7.2s   CHARGE 번개 ─ 구름 진입, 스파크 흡입
8.0s   CAST ─ 번쩍! 본줄기 (bolt_chain 당첨) 돌 4개를 튀며 건너감
8.9s   IMPACT ─ 오른쪽 끝 폭발
9.2s   AFTERMATH ─ 잔광 점선
10.4s  (콤보 당첨) CHARGE 화염 ─ 오브 주황으로
11.1s  CAST → fire_wave 불벽이 왼쪽에서 오른쪽으로
12.2s  IMPACT 폭발
12.6s  AFTERMATH ─ 연기 흐름, 그을음 회복, pose
15.0s  IDLE …
```

## 7. 완료 기준 체크리스트

- [ ] IDLE에서 최소 2개 요소(망토, 마나 입자)가 계속 움직인다
- [ ] 번개 본줄기가 스트립의 **90% 이상** 너비를 덮는다
- [ ] 번개 모양이 발동할 때마다 다르다 (시드 고정 시에는 동일)
- [ ] 번개 변형 5종, 화염 변형 5종이 가중치대로 나오고, 같은 변형이 연속으로 나오지 않는다
- [ ] 1초에 플래시 3회를 넘지 않는다
- [ ] 그을음이 3초 안에 원래 풀로 돌아온다
- [ ] 다크/라이트 모드 양쪽에서 마법사 실루엣이 식별된다
- [ ] IDLE 15fps 이하, 이펙트 구간 30fps 유지
- [ ] `W = 160`과 `W = 320`에서 모두 장면이 어색하지 않다

## 8. 미정 / 로컬에서 결정할 것

- [ ] 마법사를 왼쪽에 고정할지, 가끔 오른쪽에서 왼쪽으로 쏘는 미러 버전도 둘지
- [ ] 연쇄 번개 표식(돌/허수아비)을 배경 소품으로 늘 둘지, 발동 때만 나타나게 할지
- [ ] 소리(메뉴 막대 앱이라 기본 꺼짐) 옵션 여부
