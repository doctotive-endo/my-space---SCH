## 7. 완료 기준 체크리스트

- [ ] IDLE에서 최소 2개 요소가 계속 움직인다
- [ ] 메인 이펙트가 스트립 너비의 85% 이상을 쓴다
- [ ] 변형이 가중치대로 나오고 연속 중복이 없다
- [ ] 1초에 플래시 3회를 넘지 않는다
- [ ] 다크/라이트 모드 양쪽에서 캐릭터가 식별된다
- [ ] IDLE 15fps 이하, 이펙트 구간 30fps 유지
- [ ] `W = 160`, `W = 320` 모두 자연스럽다
- [ ] 동작 줄이기 모드에서 플래시·흔들림이 꺼진다
