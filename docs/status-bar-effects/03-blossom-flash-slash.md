# 장면 3 — 벚꽃 일섬: 번개처럼 화면을 가르는 발도

> **한 줄 컨셉**: 벚꽃잎이 흩날리는 고요 속에 칼자루에 손을 얹은 검사가 서 있다. 정적이 흐르다가 번쩍하는 순간 검사는 이미 반대편 끝에 있고, 스트립을 가른 한 줄의 빛을 따라 꽃잎이 두 동강 나며 폭발하듯 흩어진다.

| 항목 | 값 |
| --- | --- |
| 장면 ID | `blossom` |
| 우선순위 | **1순위** (스프라이트는 가장 적고 체감 효과는 가장 큼) |
| 핵심 부품 | 히트스톱·슬로모션(5.4), 잔상(5.3), 파티클(5.1), 절차적 번개(5.2, 보조), 플래시(5.5) |
| 예상 스프라이트 | 검사 1명(약 14프레임), 꽃잎 4프레임, 짚단 과녁 2프레임(+절단 상태), 칼집 넣기 3프레임 |
| 기술명 (오리지널) | **섬뢰발도(閃雷拔刀)** — 특정 작품의 기술명·의상 무늬는 쓰지 않는다 |

## 1. 무대 구성

```
 x: 0   10                                                                         W
    ┌───────────────────────────────────────────────────────────────────────────────┐
 0  │  ❀    ·      ❀         ·    ❀     (원경 꽃잎: 작고 느리고 흐림)     ·     ❀     │
 4  │       ❀            ❀                  ❀              ❀                         │
    │   o                                                                           │
11  │  /█═╕ ← 허리에 찬 칼, 손은 칼자루     │ 짚단 │       │ 짚단 │       │ 짚단 │      │
    │  / \                                  │      │       │      │       │      │      │
16  │ ───────────────────────────────── 흙길 + 군데군데 떨어진 꽃잎 ─────────────────── │
22  └───────────────────────────────────────────────────────────────────────────────┘
```

| 레이어 | 내용 |
| --- | --- |
| L0 하늘 (옵션) | 낮: 연분홍 → 투명 / 밤: 남색 + 달 |
| L1 원경 | 먼 벚나무 실루엣(아주 흐리게), 원경 꽃잎 10~15장 |
| L2 지면 | 흙길, 쌓인 꽃잎 점. 일섬이 지나간 자리에 꽃잎이 쓸려 나간 자국 |
| L3 캐릭터·과녁 | 검사, 짚단 2~4개(옵션: 가끔 대나무, 그림자 무사) |
| L4 이펙트 | 일섬 빛줄기, 지그재그 번개 잔상, 대시 잔상 |
| L5 근경 | 근경 꽃잎 15~25장(크고 빠름), 칼날 불꽃 |
| L6 오버레이 | 일섬 순간 흰 플래시, 정적 동안 채도 낮추기 |

### 대기(IDLE) 중 살아 있는 요소 — 이 장면은 IDLE이 곧 볼거리
- **꽃잎이 쉬지 않고 흩날린다.** 오른쪽 → 왼쪽 바람(기본), 가끔 돌풍(gust) 때 꽃잎이 한꺼번에 휘몰아침.
- 꽃잎 1장 = 4프레임 회전 스프라이트(정면 → 기울어짐 → 옆면 1px → 반대로 기울어짐) + 사인파 흔들림.
- 검사의 머리끈/옷자락이 바람에 2프레임 펄럭.
- 가끔(10%) 꽃잎 한 장이 검사 어깨에 내려앉았다가 다시 날아감.

#### 꽃잎 파라미터

| 항목 | 원경 | 근경 |
| --- | --- | --- |
| 개수 | 10~15 | 15~25 |
| 크기 | 1×1 ~ 2×1 | 2×2 ~ 3×2 |
| 속도 (x) | −6 ~ −10 /초 | −14 ~ −24 /초 |
| 흔들림 진폭 / 주기 | 1 / 2.5초 | 2 / 1.6초 |
| 회전 프레임 fps | 4 | 8 |
| 색 | `#F7C6D6` alpha 0.6 | `#FFB7CF`, `#FFD9E6`, 가끔 `#FFFFFF` |

## 2. 캐릭터 스프라이트 (검사)

| 동작 | 프레임 | fps | 설명 |
| --- | --- | --- | --- |
| `stance` | 3 | 4 | 발도 자세: 무릎 살짝 굽히고 몸을 낮춤, 왼손은 칼집, 오른손은 칼자루. 호흡만 |
| `focus` | 2 (루프) | 10 | 몸을 더 낮춤, 눈에서 1px 빛이 반짝 |
| `vanish` | 1 | — | 빈 프레임 (사라짐) + 발밑 흙먼지 |
| `slash_end` | 2 | 12 | 오른쪽 끝에서 칼을 휘두른 뒤의 자세 (팔 쭉 뻗음, 뒷모습) |
| `sheathe` | 3 | 8 | 칼을 천천히 칼집에 넣음. 마지막 프레임에 "딸깍" (칼코등이 1px 반짝) |
| `walk_back` | 4 | 8 | 원래 자리로 걸어서 돌아감 (변형에 따라) |

크기: **12 × 17**, 기준점: 발 가운데. 의상은 오리지널: 짙은 남색 하카마 + 흰 상의 + **붉은 머리끈 하나**를 포인트로 (멀리서도 이 붉은 점 하나로 캐릭터를 알아보게).

## 3. 시퀀스 — 섬뢰발도

| # | 상태 | 길이 | timeScale | 화면에서 일어나는 일 |
| --- | --- | --- | --- | --- |
| F1 | IDLE | 6~14초 | 1.0 | 꽃잎이 흩날리고 검사는 `stance`. 가끔 돌풍 |
| F2 | CHARGE ① 정적 | 0.8초 | 1.0 → **0.25** | 바람이 잦아들고 **모든 꽃잎이 슬로모션으로 감속**. L6 채도를 60%로. 검사 `focus`. 발밑에 노란 전기 스파크 2~3개가 지직 |
| F3 | CHARGE ② 기척 | 0.3초 | 0.25 | 검사 몸 주변 1px 노란 외곽선 깜빡. 칼자루 쪽에서 작은 번개 하나(길이 3~5). 검사 바로 앞 꽃잎 3장이 **공중에 멈춤** |
| F4 | CAST 일섬 | **0.06초** (2프레임) | 1.0 | 검사 `vanish`. 출발점 x₀ → 끝점 x₁(= W−10)까지 **직선 빛줄기 한 번에 생성**: 코어 1px `#FFFFFF` + 위아래 글로우 `#FFE66B`. 동시에 출발점~끝점 사이에 대시 잔상 실루엣 5개를 찍음. L6 플래시 alpha 0.7. 검사는 끝점에 `slash_end`로 등장 |
| F5 | 히트스톱 | 0.35초 | **0** | **전부 멈춤.** 꽃잎도 공중에 정지. 빛줄기만 살아서 미세하게 떨림(1px). 짚단 위에 아주 얇은 절단선 1px이 보임 |
| F6 | IMPACT 해방 | 0.5초 | 0 → 1.0 | ① 빛줄기 위를 지나던 꽃잎이 **위아래 반쪽으로 갈라져**(1px 조각 2개) 튕겨 나감 ② 빛줄기에서 위아래로 퍼지는 충격파(꽃잎들을 바깥으로 밀어냄) ③ 짚단 윗부분이 **비스듬히 미끄러져 떨어짐** ④ 빛줄기가 끝점 쪽부터 사라지며 노란 번개 지그재그 잔상이 0.2초 남음 ⑤ 흔들림 x ±1 |
| F7 | AFTERMATH ① 납도 | 0.8초 | 1.0 | 검사 `sheathe`. 마지막 "딸깍" 프레임에 맞춰 **떨어지던 짚단 윗부분이 땅에 닿음** (타이밍 맞추는 게 이 장면의 쾌감 포인트) |
| F8 | AFTERMATH ② 꽃보라 | 1.5~2.5초 | 1.0 | 빛줄기가 있던 선을 따라 **꽃잎이 대량으로 피어오름**(버스트 30장)하며 흩날림이 다시 시작. 지면엔 쓸려 나간 자국. 짚단은 서서히 다시 서는 연출(또는 페이드 후 새 짚단 등장) |
| F9 | 복귀 | 1~2초 | 1.0 | 변형에 따라: 걸어서 돌아감 / 꽃잎 회오리 속으로 사라졌다 원위치에 나타남 / 그 자리에서 반대 방향(오른쪽 → 왼쪽)으로 다음 일섬 준비 |

> **이 장면의 핵심 리듬**: 느림(정적 1.1초) → 극도로 빠름(0.06초) → 완전 정지(0.35초) → 폭발(0.5초) → 느린 여운. 길이 비율을 지키는 게 이펙트 화려함보다 중요하다.

### 일섬 빛줄기 파라미터

| 파라미터 | 기본값 | 범위 |
| --- | --- | --- |
| 코어 두께 | 1px | 강한 변형 2px |
| 글로우 | 위아래 각 1px, alpha 0.6 | |
| 길이 | 스트립의 **85~95%** | |
| 유지 | F4~F6 동안, 이후 0.15초 페이드 | |
| 잔상 실루엣 개수 | 5 | 4~7 |
| 잔상 색 | `#FFE66B` alpha 0.5 → 0.1 | |
| 노란 지그재그 잔상 | 절차적 번개 `depth 5, roughness 2` (빛줄기 주변으로만) | |

### 꽃잎 절단 판정
- 빛줄기 y ±1 범위 안의 꽃잎 = "베인 꽃잎".
- 베인 꽃잎은 지우고, 그 자리에 반쪽 조각 2개를 만든다: 위 조각 `vy = −8~−14`, 아래 조각 `vy = +6~+10`, 둘 다 `vx`는 원래 속도 + 일섬 방향으로 +4, 회전 빠르게, 수명 0.8초.
- 빛줄기 y ±5 범위 꽃잎 = 충격파로 바깥 방향 속도 +10.

## 4. 변형 (가중치)

| ID | 가중치 | 내용 | 가로 공간 활용 |
| --- | --- | --- | --- |
| `single` | 40 | 기본: 직선 일섬 1회 (위 시퀀스 그대로) | 한 줄로 스트립 관통 |
| `zigzag` | 25 | **지그재그 연속 일섬**: 짚단 3~4개를 위·아래로 꺾으며 연달아 벰. 빛줄기가 번개 모양 꺾은선이 됨(각 꼭짓점에 0.04초 정지, 꼭짓점마다 작은 플래시는 생략해 3회 규칙 지킴). 히트스톱은 맨 끝에 한 번만 | 꺾은선이 세로 존까지 씀 |
| `six_cut` | 15 | **찰나의 연타**: 짚단 하나 앞에서 0.3초 동안 X자 빛줄기 6개가 연달아 번쩍 → 히트스톱 → 짚단이 조각조각 흩어짐. 그 뒤 남은 거리는 평범한 일섬으로 | 중앙에서 화려함 집중 |
| `return` | 10 | **왕복**: 오른쪽 끝에 도착한 직후 반대로 한 번 더 일섬해서 원위치로 복귀. 빛줄기 2줄이 위아래로 1px 어긋나게 겹침 | 왕복으로 두 번 덮음 |
| `moonlit` ★레어 | 5 | **밤 + 달**: L0가 남색 하늘로 바뀌고 달이 뜸. 꽃잎이 은은하게 빛남(add). 일섬 색이 푸른 은색 `#CFE4FF`. 일섬 직후 달 앞으로 꽃잎 회오리 | |
| `petal_storm` ★레어 | 5 | **꽃보라**: 일섬 후 꽃잎 수가 3배로 늘어 10초 동안 스트립 전체가 분홍빛으로 휘몰아침 | 배경 전체 |

- 과녁 대체(랜덤): 짚단 70% / 대나무 20%(베이면 위쪽이 기울어 쓰러짐) / 그림자 무사 10%(베이면 검은 연기로 흩어짐).

## 7. 완료 기준 체크리스트

- [ ] IDLE에서 꽃잎이 원경/근경 2층으로 흩날리며, 돌풍이 가끔 온다
- [ ] 정적 구간에서 꽃잎이 **눈에 띄게 느려진다** (timeScale 0.25)
- [ ] 일섬 빛줄기가 **2프레임 안에** 스트립의 85% 이상을 가로지른다
- [ ] 히트스톱 동안 꽃잎·짚단이 완전히 정지하고, 빛줄기만 떨린다
- [ ] 빛줄기 위의 꽃잎이 반쪽으로 갈라지는 게 보인다
- [ ] 납도 "딸깍" 타이밍에 짚단이 땅에 닿는다 (±1프레임)
- [ ] 변형 6종이 가중치대로 나오고 연속 중복이 없다
- [ ] 1초에 플래시 3회를 넘지 않는다 (zigzag 포함)
- [ ] 붉은 머리끈 하나로 다크/라이트 모드에서 캐릭터 위치가 바로 보인다
- [ ] 동작 줄이기 모드에서는 플래시·흔들림 없이 빛줄기와 꽃잎 절단만 나온다

## 8. 미정 / 로컬에서 결정할 것

- [ ] 일섬 방향: 항상 왼쪽 → 오른쪽? 아니면 번갈아?
- [ ] 과녁 없이 "꽃잎만 베는" 미니멀 버전을 기본으로 할지
- [ ] 탭/클릭하면 바로 일섬하는 "인터랙티브 모드" (가장 손맛 좋은 장면이라 추천)
- [ ] 기존 검도 캐릭터와 세계관을 이을지 (같은 캐릭터가 죽도 대신 진검을 쓰는 "각성" 버전 등)
