# 공통 엔진 규격 (ENGINE)

세 장면이 같이 쓰는 규격입니다. 숫자는 권장 기본값이고, 로컬 앱의 현재 값이 있으면 그걸로 바꿔서 쓰세요. 표의 `[ ]` 칸은 로컬에서 실제 값을 확인하고 채우는 자리입니다.

---

## 1. 캔버스 (스트립) 규격

### 1.1 논리 좌표계

| 항목 | 기본값 | 비고 |
| --- | --- | --- |
| 논리 높이 `H` | **22** 단위 | 1단위 = 1pt(mac) / 1dp(Android) |
| 논리 너비 `W` | **220** 단위 (10:1) | 설정에서 160 / 220 / 320 / "가능한 최대" 선택 |
| 픽셀아트 그리드 | 1단위 = 1 아트 픽셀 | 기기 배율(@2x, @3x)로 **정수배 확대**, nearest-neighbor 필터 |
| 원점 | 좌상단 (0,0) | y는 아래로 증가 |
| 현재 앱 실제 값 | `[ ]` × `[ ]` | 로컬에서 확인 |

### 1.2 세로 존(zone) 나누기

높이가 22밖에 안 되니 층을 미리 정해 두면 장면끼리 일관성이 생깁니다.

```
y= 0 ┌──────────────────────────────────────────────── 하늘/상단 이펙트 (구름, 새, 번개 가지)
y= 4 ├────────────────────────────────────────────────
     │  메인 이펙트 레인 (빔, 화염, 일섬, 달리는 동물)        ← 가로 이펙트가 주로 지나가는 곳
y=16 ├────────────────────────────────────────────────
     │  지면 (풀, 마법진, 그을음, 꽃)
y=22 └────────────────────────────────────────────────
```

- 캐릭터 키: **14~18 단위** (y=4~20 정도). 머리·무기 끝 정도만 상단 존에 걸쳐도 된다.
- 메인 이펙트 레인 중심선: **y = 11** (캐릭터 손/무기 높이와 맞춘다).

### 1.3 데드 존 (가려지는 구간)

| 플랫폼 | 가리는 것 | 대응 |
| --- | --- | --- |
| macOS 노치 모델 | 메뉴 막대 가운데 노치 / 다른 메뉴 막대 아이콘 | 상태 항목 너비가 줄어들 수 있음 → `W`가 바뀌어도 장면이 성립하게 **모든 위치는 `W` 비율로 계산** |
| Android | 펀치홀 카메라, 시계·배터리 아이콘 | 설정에 "데드 존 구간(x 시작~끝)" 입력 → 그 구간에서는 캐릭터를 멈추지 않고, 이펙트만 그냥 지나가게 |

**규칙: 캐릭터의 대기 위치와 이펙트의 "타격 지점"은 데드 존에 두지 않는다.**

### 1.4 배경 투명도 & 라이트/다크

- 상태 표시줄은 배경이 반투명이거나 테마에 따라 바뀐다 → **기본은 배경 투명**, 하늘 그라데이션은 옵션.
- 모든 스프라이트에 **1px 외곽선**: 다크 모드에서는 어두운 외곽선 + 밝은 몸체, 라이트 모드에서는 반대로 외곽선 색만 바꾼 팔레트 스왑.
- 빛 이펙트(번개, 화염, 정령)는 **가산 혼합(additive)** + 반투명 글로우 1~2px → 어느 배경에서도 잘 보인다.

## 2. 레이어 구조 (뒤 → 앞)

| # | 레이어 | 예시 | 스크롤 계수 |
| --- | --- | --- | --- |
| L0 | 하늘 (옵션) | 그라데이션, 달, 노을 | 0 |
| L1 | 원경 | 먼 산, 먼 벚꽃잎, 구름 | 0.2 |
| L2 | 지면 | 풀 타일, 마법진, 그을음 | 1.0 |
| L3 | 캐릭터 | 마법사, 드루이드, 검사 | — |
| L4 | 메인 이펙트 | 번개, 화염파, 정령 동물, 일섬 선 | — |
| L5 | 근경 파티클 | 불씨, 스파크, 가까운 꽃잎, 앞쪽 풀 끝 | 1.4 |
| L6 | 전체 오버레이 | 화면 플래시, 색조 변화, 비네팅 | — |

- 각 레이어는 독립된 `update(dt)` / `draw(ctx)`를 가진다.
- L6 플래시는 **스트립 전체 밝기/색만** 바꾼다 (픽셀을 새로 그리지 않음 → 저렴).

## 3. 장면 상태 머신

모든 장면은 아래 공통 흐름을 따르고, 장면마다 상태 안의 내용만 다르다.

```
            ┌─────────────────────────────────────────────┐
            ▼                                             │
 ┌──────┐  대기시간 만료  ┌────────┐   ┌──────┐   ┌────────┐  ┌────────┐  ┌──────────┐
 │ IDLE │ ─────────────▶ │ CHARGE │──▶│ CAST │──▶│ TRAVEL │─▶│ IMPACT │─▶│ AFTERMATH│
 └──────┘                └────────┘   └──────┘   └────────┘  └────────┘  └──────────┘
    ▲  (탭/클릭 시 바로 CHARGE로 — "한 번 더 보기")                              │
    └────────────────────────────────────────────────────────────────────────────┘
```

| 상태 | 역할 | 기본 길이 |
| --- | --- | --- |
| IDLE | 숨쉬기, 배경 레이어만 움직임. 대부분의 시간 | 4~12초 (랜덤) |
| CHARGE | 기 모으기, 예고. "곧 뭔가 터진다"는 신호 | 0.4~1.0초 |
| CAST | 발사 순간. 플래시·히트스톱이 들어가는 곳 | 0.05~0.2초 |
| TRAVEL | 이펙트가 가로로 이동/확장 | 0.3~1.5초 |
| IMPACT | 오른쪽(또는 목표) 지점에서 폭발/분해 | 0.2~0.5초 |
| AFTERMATH | 여운: 불씨, 잔광, 떨어지는 꽃잎, 원상 복귀 | 1~3초 |

- 상태 하나 = `{ enter(), update(dt), exit(), duration }`.
- **콤보**: AFTERMATH에서 일정 확률로 IDLE을 건너뛰고 다음 CHARGE로 바로 넘어간다 (예: 번개 → 화염).

## 4. 랜덤 규칙

| 규칙 | 내용 |
| --- | --- |
| 시드 RNG | `mulberry32(seed)` 같은 시드 기반 난수. 디버그할 때 같은 시드로 같은 장면 재현 |
| 가중치 변형 선택 | `variants: [{id, weight}]`에서 가중치 랜덤 |
| 연속 금지 | 직전 변형과 같은 건 가중치 0 (최근 2개까지 기억) |
| 희귀 이벤트 | 3~5% 확률의 "레어 변형". 사용자가 발견하는 재미 |
| 지터(흔들림) | 모든 시간·위치·개수에 ±10~25% 흔들림 |
| 시간대 반영 (옵션) | 기기 시각에 따라 낮/노을/밤 팔레트 |
| 상태 반영 (옵션) | 배터리 충전 중이면 에너지 많은 변형 가중치 올리기, 방해금지 모드면 IDLE 길게 |

## 5. 이펙트 부품 (프리미티브)

### 5.1 파티클 이미터

```ts
interface EmitterConfig {
  rate: number;             // 초당 생성 수 (버스트면 0)
  burst?: number;           // 한 번에 생성
  life: [min: number, max: number];       // 초
  speed: [number, number];  // 단위/초
  angle: [number, number];  // 도(deg), 0 = 오른쪽
  gravity: number;          // +면 아래로
  drag: number;             // 0~1, 프레임당 감속
  size: [number, number];   // 1~3 단위
  colors: string[];         // 수명에 따라 순서대로 변하는 색
  blend: 'normal' | 'add';
  maxAlive: number;         // 이 이미터의 상한
}
```

- **전체 파티클 상한: 120개** (넘으면 오래된 것부터 제거).
- 파티클은 객체 풀(pool)로 재사용 → GC 끊김 방지.

### 5.2 절차적 번개 (Lightning Bolt)

중점 변위(midpoint displacement)로 지그재그 선을 만든다.

```
function bolt(x0, y0, x1, y1, roughness, depth):
    if depth == 0: return [(x0,y0), (x1,y1)]
    mx = (x0+x1)/2
    my = (y0+y1)/2 + rand(-1,1) * roughness
    return bolt(x0,y0,mx,my, roughness/2, depth-1) + bolt(mx,my,x1,y1, roughness/2, depth-1)
```

- 가로 220단위 기준 `depth = 6~7`, `roughness = 4~6` (세로 22를 넘지 않게 y를 clamp).
- 가지(branch): 중간 점 일부(15~25%)에서 짧은 번개를 비스듬히 분기, 길이는 본줄기의 10~25%.
- 그리기: 코어 1px 흰색 + 양옆 1px 하늘색 글로우(add 혼합, alpha 0.5).
- **2~3프레임마다 모양을 새로 생성**해서 지직거리는 느낌을 준다.

### 5.3 잔상 (Afterimage / Trail)

- 빠른 대상은 최근 N개 위치를 링 버퍼에 저장하고, 오래된 것일수록 alpha를 낮춰 그린다.
- N = 3~6. 일섬처럼 순간이동하는 건 시작점~끝점을 잇는 실루엣 4~6개를 한 번에 찍고 0.3초 동안 페이드.

### 5.4 히트스톱 & 시간 배율

- 전역 `timeScale`을 둔다. 모든 `update(dt)`는 `dt * timeScale`을 받는다.
- 히트스톱: `timeScale = 0`을 0.06~0.3초 유지 (단, 플래시·글로우 깜빡임은 실시간으로).
- 슬로모션: `timeScale = 0.2~0.4` (일섬 직전 "정적"에 사용).

### 5.5 화면 플래시

- L6에서 스트립 전체를 흰색/색상으로 덮고 alpha 0.6 → 0으로 80~150ms 안에 감쇠.
- **광과민성 안전 규칙: 1초에 3번 넘게 번쩍이지 않는다** (WCAG 2.3.1). 번개 재타격도 이 규칙을 따른다.

### 5.6 화면 흔들림

- 스트립 전체를 x ±1단위로 흔든다 (세로는 흔들지 않음 — 높이가 작아서 잘림이 티 남).
- 0.1~0.2초, 감쇠.

### 5.7 시차 스크롤러

- 타일 너비 `tw`의 이미지를 `offset = (offset + speed * factor * dt) mod tw`로 반복해서 그린다.
- 바람(gust) 이벤트 때 `speed`를 잠깐 올렸다가 내린다 → 풀·꽃잎이 같이 반응.

## 6. 스프라이트 규칙

| 항목 | 규칙 |
| --- | --- |
| 형식 | PNG 스프라이트 시트 (가로로 프레임 나열) + JSON 메타데이터 |
| 이름 | `{장면}_{대상}_{동작}.png` 예: `wizard_body_cast.png` |
| 프레임 크기 | 대상마다 고정 (예: 마법사 16×18). 시트 안에서는 동일 크기 |
| 기준점(pivot) | 발 가운데 (bottom-center). 메타데이터에 `pivot: [x, y]` |
| 팔레트 | 장면당 16색 이내 + 외곽선 2색 (다크/라이트) |
| 애니메이션 FPS | 스프라이트 8~12fps (픽셀아트 느낌 유지), 이펙트·파티클은 렌더 FPS로 |

메타데이터 예:

```json
{
  "image": "wizard_body_cast.png",
  "frameSize": [16, 18],
  "pivot": [8, 18],
  "animations": {
    "idle":   { "frames": [0, 1, 2, 1], "fps": 6, "loop": true },
    "charge": { "frames": [3, 4], "fps": 10, "loop": true },
    "cast":   { "frames": [5, 6, 7], "fps": 12, "loop": false }
  }
}
```

## 7. 성능 예산

| 항목 | 목표 |
| --- | --- |
| IDLE 렌더 | **10~15 fps** (배경만 천천히) |
| 이펙트 구간 렌더 | **30 fps** (최대 60, 기기 여유가 있을 때만) |
| CPU (mac 메뉴 막대) | 평균 1% 미만, 이펙트 순간 5% 미만 |
| 메모리 | 장면당 텍스처 2MB 미만 |
| 일시정지 조건 | 화면 꺼짐, 저전력 모드, 전체화면 앱 실행 중, 상태 항목이 숨겨짐 |

- mac: `NSStatusItem` 이미지를 매 프레임 새로 만드는 방식이면 비용이 크다 → 커스텀 `NSView`(layer-backed)에 직접 그리는 쪽을 권장. `[ ]` 현재 방식 확인.
- Android: 오버레이 뷰라면 `Choreographer` 프레임 콜백에서 그리고, IDLE에는 콜백 간격을 늘린다. `[ ]` 현재 방식 확인.

## 8. 접근성 & 설정 항목

| 설정 | 기본값 | 동작 |
| --- | --- | --- |
| 동작 줄이기 | 시스템 설정 따름 | 켜면 플래시·흔들림 끄고, 이펙트 빈도 1/3로 |
| 플래시 | 켬 | 끄면 L6 플래시 대신 이펙트 자체 밝기만 올림 |
| 빈도 | 보통 | 드물게(IDLE 15~30초) / 보통 / 자주(IDLE 2~5초) |
| 장면 선택 | 순환 | 고정 / 순환 / 랜덤 |
| 탭/클릭 반응 | 켬 | 누르면 바로 CHARGE (쿨다운 2초) |

## 9. 디버그 도구 (개발용)

- `?seed=1234` 또는 설정값으로 시드 고정.
- 키 단축키: `1~9` 변형 강제, `Space` 즉시 발동, `S` 슬로모션 0.25배, `G` 존/데드존 가이드 선 표시.
- 화면 구석에 파티클 수, fps, 현재 상태 이름 표시.
